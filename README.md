## 🗂️ Организация репозитория

Каждый модуль содержит собственный отчёт `notebook.ipynb`, исходные данные в `data/`, обученные модели и метрики в `models/`, а также иллюстрации в `examples/`. Подробности, зависимости и инструкции запуска — в README соответствующего модуля.

## 🚀 Запуск проектов

1. Откройте нужную папку `module-N-...`.
2. Установите зависимости из `requirements.txt`, если он присутствует: `python -m pip install -r requirements.txt`.
3. Откройте `notebook.ipynb` в Jupyter и выполните ячейки по порядку. Для воспроизводимости запускайте ноутбук из каталога соответствующего модуля.
4. Результаты измерений проверяйте по `models/metrics.json`, изображения — в `examples/`.

**Данные и модели:** ссылки на исходные наборы данных приведены в описаниях модулей. Сохранённые файлы `.pkl` следует загружать только из доверенного репозитория: форматы на основе pickle при чтении могут выполнять произвольный код.
