# Данные

Оригинальные `train.csv` (1460 строк) и `test.csv` (1459 строк) соревнования House Prices. 

Скачайте с https://www.kaggle.com/competitions/house-prices-advanced-regression-techniques/data и сохраните под этими именами в этой папке. При отсутствии файлов ноутбук пробует скачать копию с https://github.com/Rswcf/houseprices_kaggle.

После запуска ноутбука автоматически создаётся `house_prices_info.md` с описанием всех столбцов и пропусков.
