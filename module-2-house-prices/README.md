## 🎯 Задача

Прогнозировать стоимость недвижимости (`SalePrice`) по характеристикам домов. Работа включает обработку пропусков и выбросов, кодирование категорий, масштабирование, создание новых признаков и обучение линейных моделей с регуляризацией. Для уменьшения асимметрии обучение проводилось в пространстве `log1p(SalePrice)`, а денежные ошибки рассчитывались после обратного преобразования.

## 📊 Результаты на отложенной выборке

| Модель | RMSE (log) | MAE (log) | R² (log) | RMSE ($) | Обучение, с |
|---|---:|---:|---:|---:|---:|
| Linear Regression | 0.1232 | 0.0873 | 0.9187 | $22 367 | 0.345 |
| Ridge | 0.1217 | 0.0859 | 0.9206 | $22 044 | 1.138 |
| Lasso | 0.1207 | 0.0826 | 0.9220 | $21 825 | 2.658 |
| ElasticNet | 0.1191 | 0.0821 | 0.9239 | $21 394 | 4.610 |
| Random Forest (bonus) | 0.1434 | 0.0939 | 0.8898 | $27 973 | 0.588 |

**Лучшая модель по R² (log) и RMSE ($) — ElasticNet:** R² = 0.9239; RMSE ≈ $21 394. Подобранные параметры: `alpha=0.003`, `l1_ratio=0.8`.

Выполните все ячейки сверху вниз. Сохранённая модель находится в `models/best_model.pkl`, а масштабировщик — в `models/scaler.pkl`. Для прогноза используйте тот же порядок признаков и этапы предобработки, которые применялись при обучении.

- На этом разбиении ElasticNet показал меньшую ошибку, чем остальные модели из сравнения.
