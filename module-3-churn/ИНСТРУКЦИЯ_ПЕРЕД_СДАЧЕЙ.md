# Проверка перед сдачей модуля 3

1. Откройте `notebook.ipynb` и замените в титульном листе поля с группой, отчеством и ФИО преподавателя на свои данные.
2. Установите Python 3.11 и зависимости: `python -m pip install -r requirements.txt`.
3. Сохраните оригинальный CSV как `data/telco_churn.csv` либо разрешите ноутбуку загрузить его из репозитория IBM. Требуется исходная таблица из 7043 строк и 21 столбца.
4. Выполните ячейки ноутбука по порядку (**Restart & Run All**). Рекомендуется выделить время на 30 испытаний Optuna и SHAP.
5. Проверьте рассчитанные метрики в `models/metrics.json`, обученные модели `.pkl` и сохранённые графики в `examples/`. Если требуются выводы с конкретными числами, перенесите результаты из таблиц разделов 7 и 9 в текстовый анализ.
6. Запустите `python predict_saved.py`, чтобы проверить обработку пяти клиентов по оригинальному файлу.
7. Скопируйте папку `module-3-churn/` в существующий `ml-course-cherepanov` (рядом с модулями 1 и 2). Файл `README.md` в корне архива — образец для объединения с уже существующим README, не заменяйте им важную информацию о предыдущих модулях.
8. После `git add`, `git commit`, `git push` проверьте, что `.pkl` находятся в ветке `main`, затем установите `CHECK_GITHUB = True` в разделе 12 и выполните ячейку повторно. Если GitHub отвечает 404 — проверьте имя пользователя, репозитория, ветку и путь к файлу.
9. Убедитесь, что отправляете ссылку на репозиторий, прямую ссылку на ноутбук и скриншот таблицы метрик.

Примеры команд из корня существующего репозитория:

```bash
git add module-3-churn/ README.md .gitignore
git commit -m "Module 3: Customer Churn ensembles, Optuna and SHAP"
git push origin main
```

`.pkl`-файлы загружайте только из своего доверенного репозитория.
