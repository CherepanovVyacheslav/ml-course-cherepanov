# Проверка перед сдачей Модуля 4

1. Заполнить в `notebook.ipynb` отчество, номер группы и преподавателя.
2. Скачать исходный CSV (автоматически: `python download_dataset.py`). В `data/online_shoppers_intention.csv` должны быть ровно 12 330 строк и 18 столбцов.
3. Установить зависимости `python -m pip install -r requirements.txt`.
4. В папке `module-4-features/` выполнить ноутбук целиком (Kernel → Restart & Run All) или запустить `run_all_windows.bat`.
5. Проверить результаты в разделе 7 и наличие `.pkl` и `.json` в `models/`, а также PNG в `examples/`.
6. Загрузить папку `module-4-features` в **существующий** единый репозиторий `ml-course-cherepanov`, обновить корневой README по фактическим метрикам.
7. Повторно выполнить раздел 12, чтобы подтвердить скачивание модели по raw-ссылке. До публикации HTTP 404 ожидаем.
8. Открыть ноутбук в GitHub, проверить выводы, приложить ссылку на модуль и скриншот метрик из раздела 7.

Результаты демонстрационного теста на искусственных данных не входят в пакет и не должны использоваться в отчёте.
