## 🎯 Задача

Прогнозирование покупки (`Revenue`) по характеристикам сессии интернет-магазина. Созданы признаки, описывающие суммарные просмотры, длительность, интенсивность взаимодействий и календарные особенности. Обучены Random Forest, XGBoost, LightGBM и CatBoost; LightGBM дополнительно настроена с помощью Optuna, после чего построены графики SHAP.

## 📊 Результаты на отложенной выборке

| Модель | Accuracy | Precision | Recall | F1 | ROC-AUC | Обучение, с |
|---|---:|---:|---:|---:|---:|---:|
| Random Forest | 0.8678 | 0.5500 | 0.8063 | 0.6539 | 0.9282 | 0.601 |
| LightGBM | 0.8747 | 0.5690 | 0.7880 | 0.6608 | 0.9275 | 0.335 |
| CatBoost | 0.8702 | 0.5568 | 0.7958 | 0.6552 | 0.9251 | 1.948 |
| XGBoost | 0.8800 | 0.5943 | 0.7094 | 0.6468 | 0.9228 | 0.774 |
| LightGBM (Optuna) | 0.8613 | 0.5332 | 0.8403 | 0.6524 | 0.9326 | 0.362 |

**Лучший ROC-AUC — LightGBM (Optuna):** 0.9326; Recall = 0.8403; ROC-AUC на кросс-валидации при подборе параметров = 0.9361. В сравнении с базовой LightGBM ROC-AUC вырос с 0.9275 до 0.9326; при этом Precision и Accuracy снизились, что важно при выборе рабочего порога.

## 🚀 Быстрый старт

```powershell
cd module-4-features
python -m pip install -r requirements.txt
jupyter notebook notebook.ipynb
```

Запускайте ноутбук из папки модуля. Исходный CSV уже предусмотрен в `data/`; по окончании расчётов модели, метрики и графики сохраняются в соответствующие папки. Для повторного прогнозирования необходимо использовать тот же набор столбцов и подготовку, что и при обучении.

## 📁 Содержимое

- `notebook.ipynb` — полный отчёт с 14 разделами;
- `data/online_shoppers_intention.csv`, `data/dataset_info.md` — данные и их описание;

## 💡 Основные выводы

- `PageValues` и показатели просмотра страниц помогают оценивать интерес к покупке, однако их доступность на момент прогноза необходимо проверять отдельно.
- Созданные признаки агрегируют поведение пользователя: например, `TotalPages` суммирует посещённые страницы, а `TotalDuration` — время просмотра.
- Из-за преобладания сессий без покупки дополнительно к Accuracy анализировались ROC-AUC, Precision, Recall и F1.
